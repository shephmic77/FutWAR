# Reports and generated outputs

Run `py scripts/audit_data.py` from the project root. Machine-generated tables, row-level exports, database files, and explorer bundles are kept local and ignored by Git. This protects source data and keeps large derived exports out of the public repository.

Reviewed narrative summaries and explicitly selected methodology figures may be versioned after checking their source terms and attribution. This folder is not a complete data release. See the root README and `docs/data_sources.md` for project status, source coverage, and limitations.
