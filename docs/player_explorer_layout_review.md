# Desktop layout review

The owner authorized a visual mockup after questions 1–44. This review does not replace the existing player explorer or finalize research decisions.

Editable fragment: `profile/layout_review.html`. Populate it from the existing private player-profile export:

```powershell
py scripts/build_layout_review.py '<review-output.html>'
```

The mockup provides search-first navigation, light/dark themes, team accents, player sections, a real-data scatterplot and a two-player comparison. The search review samples are Mohamed Salah and Harry Kane, 2017–18. Scatter points use 207 original-source broad FW club-season records with at least 900 minutes and available axis metrics; this is explicitly a provisional preview pool, not the approved detailed-position cohort. Displayed player rates and team results come from the existing export without modifications to raw data or research analysis.

Historical specific roles, injuries, historical market values and validated overall value are unavailable states. The season slider and exports are disabled placement previews. Multi-period aggregation, exact-position cohorts, team comparison, broader asset coverage and full export behavior remain implementation work.

Source image attribution remains accessible in Sources & exports. The private review now uses the genuine Liverpool badge served by the Premier League, archived unchanged with its URL, hash and rights limitation in `data/layout_full_crest_manifest.json`. The club retains its rights; no open license or permission for public redistribution is claimed. The previous wordmark and an inspected official Liver Bird emblem remain archived.

Owner-requested revisions add team-color surfaces, larger supporting text, a horizontal y-axis title, more chart margins and a full-width analysis chart. The context page now includes source-record appearances, starts, minutes per appearance and expanded team results. The detailed table includes all ten existing outfield metrics with totals and per-90 rates. Totals other than goals/assists are reconstructed from the existing high-precision rates and exposure, rounded to the source metric precision. Original-source row IDs, league/season/club/name alignment, minutes and source hash are checked before adding fields. Search covers the 207 preview records rather than only two examples.

Salah displays RW per the owner's explicit request. The annotation is retained separately in `data/profile_display_annotations.json`; it does not modify the analysis main position or silently replace the broad-FW preview cohort. Evidence describes this distinction.

`data/profile_context_notes.json` now records manually reviewed profile references for Salah and Kane. Basic height, foot and birth-date fields are read from the hashed publisher archive after exact-name, birth-year and nationality checks against those reviewed references. This is limited profile enrichment, not an automatic statistical identity merge. Kane displays the provider's Centre-Forward profile label; neither label proves the most-minute seasonal role.

Salah's context includes a partial documented injury event from Liverpool's 4 January 2018 report and the incoming transfer described by AS Roma on 22 June 2017 (effective 1 July). The initial €42m fee and up-to-€8m clauses remain distinct from market value. Links appear beside summaries. Injury duration, complete injury coverage and complete transfer history are not asserted. Historical market-value and role-change histories remain compact coverage notices. Existing latest/peak valuation fields are not backfilled into 2017–18.

Validation: JavaScript syntax check and browser inspection of search, profile, chart options, themes and comparison. Browser review is for the mockup rather than proof that the full proposed explorer has been implemented.

The updated browser check confirmed 14px horizontal y-axis text, the expanded analysis chart, RW/CF display labels in comparison, sourced Salah context, and correct Lewandowski/Bayern context after selection and reload. Persisted selections now use source record IDs; the earlier two-example name lookup could restore the wrong profile after selecting a scatter point. Team-inspired accents reuse the existing prototype palette, with a neutral fallback where no team palette is reviewed. The final screenshot is `reports/futwar-layout-review.png`.

The owner subsequently reported inaccessible player/search actions and requested a warm off-white theme with color only as accents, explicitly rejecting a green theme. Revision 4 adds always-visible search across all views, clickable comparison player names and profile buttons, and direct example-player buttons on the landing page. Persistence failures cannot interrupt navigation; versioned state updates reject stale echoes rather than rerendering and resetting current interactions. Previous-version state starts at the refreshed light landing page. The refreshed fragment has its own path and root ID so it can be reviewed independently of older previews.

The light palette now uses warm stone (`#eee8df`) and cream (`#f8f3eb`) with neutral charcoal text, small bronze landing accents, and team/league colors for selected controls and chart marks. Large hero surfaces stay neutral. No green pitch theme is introduced. Browser checks passed home search → Salah profile → global search → Kane profile → comparison → clickable Salah name → Salah profile, and chart-point preview → View profile. JavaScript syntax checks passed. These checks verify the local browser wrapper; the exact desktop inline host is not directly inspectable through this QA tab.

The subsequent enrichment pass simplifies labels to `Age: 25` and single role codes, and uses original three-letter nationality codes consistently. Search is independent of chart eligibility: all 1,503 available 2017–18 outfield export records are searchable, including Dybala's mixed MF,FW source label. The provisional scatter cohort follows the selected record's broad source position, with the pool and record count shown explicitly. This is not the approved detailed-position classification. The existing export itself focuses on 900+ minutes; this preview does not introduce a new eligibility rule.

The builder now enriches all 11,889 outfield export records across all 40 league-season cells. It adds source-row age, nationality, appearances, starts, goals and assists, validating names, club, league, season and minutes against the hashed processed source. It reuses the existing identity audit's unique name/birth-year candidates with historical club-season appearance evidence for 11,170 profile references. These remain provisional profile links, not verified statistical identities. Current archived profile positions, height, preferred foot and birth date are displayed with explicit evidence warnings; no historical main-position or research classification is changed.

The separate full-scope export is `reports/player_profile/enriched_data.json`; the standalone page is `reports/player_profile/FutWAR_Player_Explorer_Enriched.html`. The original analysis export remains unchanged, and keeper records retain their existing fields. `layout_enrichment_coverage.csv` and `enrichment_run.json` record coverage and missing histories. Injury, transfer and market-value histories are not declared complete. Remaining portraits, club crests, unresolved identities and historical positions are explicit gaps.

All five leagues have sourced logos. Napoli's crest and Insigne's licensed portrait are archived in `data/layout_additional_assets.json`, including URLs, hashes, retrieval time and license/author fields. Logos illustrate identity and are not guaranteed to match the historical season edition. Image credits appear in the evidence section. Dot previews show portraits or an honest unavailable fallback, position codes, and club crests or an unavailable notice. Insigne's portrait is Tifosolonapoli 7, CC BY-SA 3.0; the original image is unchanged, displayed with CSS fit/crop. Reacquisition uses `py scripts/acquire_layout_additional_assets.py` and stops on network errors instead of circumventing rate limits.

The inline payload uses lossless gzip compression of compact records, decoded locally with the browser's `DecompressionStream`; no network data request is made. Assets are embedded once. Validation confirmed Dybala search and SS profile label, Insigne's LW/ITA labels, both Insigne images and Napoli crests, Serie A logo, and the 207-record FW versus 153-record MF,FW chart pools. The screenshot is `reports/futwar-enriched-preview.png`.

Keeper profile enrichment and most player/club imagery remain unfinished.
