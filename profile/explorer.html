Current model direction

Estimate each action’s change in expected goal difference, then compare the player’s season contribution with a season-specific reference. Test adjusted lineup impact and teammate uplift as distinct signals so the same team value is not counted twice. Keep goalkeeper measurement separate until it can be calibrated to the same scale.
